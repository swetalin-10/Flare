# 🟦 DonationBox – Simple Solidity Donation Smart Contract

A very beginner-friendly smart contract that allows anyone to donate crypto while giving the owner full control to withdraw the collected funds.  
This project is perfect for learning how Ethereum smart contracts work, especially if you're new to Solidity.

---

## 📌 Project Description

DonationBox is a simple Solidity smart contract designed to collect donations in the form of cryptocurrency.  
Anyone can send funds to the contract, and only the owner (the person who deployed the contract) can withdraw the total balance.

It is intentionally kept easy to understand, making it ideal for beginners exploring blockchain development.

---

## 🎯 What It Does

- Accepts donations from any wallet  
- Stores the total money received  
- Allows the owner to withdraw all funds  
- Shows transparency with public variables like `owner` and `totalMoney`

---

## ✨ Features

- **Beginner-Friendly Code** — clean, minimal Solidity structure  
- **No Complex Logic** — no mappings, no arrays, no loops  
- **Transparent** — total donations and owner are publicly visible  
- **Secure Access Control** — only owner can withdraw funds  
- **Perfect for Learning** — ideal example project for GitHub portfolios
